# Front-end — Recarga do cartão do RU

Protótipo em Next.js 14 (App Router), TypeScript e Tailwind CSS. Telas: login, carteira com saldo, solicitação de recarga, pagamento com QR Code Pix e histórico.

Consome a API da raiz do repositório em `http://localhost:3003` (definido em `src/services/api.jsx`).

```bash
npm install
npm run dev     # http://localhost:3000
```

Visão geral do projeto no [README principal](../README.md).
